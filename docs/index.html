极简 Set-of-Mark 截图标注工具

为 VLM 视觉指令与界面评审打造的浮动批注弹窗与网页工作台：点击即打点编号（1, 2, 3），Alt+Click 同组多选（1.1, 1.2…），支持拖拽微调、右键单删、半透明标记主题与一键双贴。

GitHub Repository Install DX Plugin

单选与同组多选

左键单击生成主编号 1, 2, 3；按住 Alt 或开启「多选」连续点击同一组添加 1.1, 1.2, 1.3 与虚线引导。

箭头、拖拽与单点删除

半透明高对比标牌配实心指向箭头；左键拖动任意标点改位置，右键单独删除任一子标点并自动重排。

网页交互工作台

按 Ctrl+O 在外部浏览器打开完整标注工作台，继承当前图片、标点、评论与主题，支持继续编辑与导出。

DX Clip 一键双贴

与 dx-clip 深度联动，Ctrl+Alt+1 自动把 SoM 图片与 Markdown 指令连续粘贴到当前聊天框。

快捷键速查

快捷键功能
Ctrl + Alt + A启动 DX PinShot 区域截图与标注
Ctrl + Alt + 1一键双贴（先贴 SoM 图片再贴 Markdown 指令）
Ctrl + Shift + A保留原 Flameshot 区域截图
F11 / Ctrl + O全屏标注切换 / 外部网页工作台打开
